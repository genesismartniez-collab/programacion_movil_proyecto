1. Descripción general

Variedades Genali es un sistema completo para administrar una tienda de ropa, calzado y accesorios. Permite gestionar el catálogo de productos con fotos, registrar ventas que descuentan el inventario en tiempo real, administrar empleados y consultar reportes. El sistema se compone de tres partes que comparten una misma base de datos:

Aplicación móvil

Hecha en Flutter (Dart). Para uso diario de gerentes y empleados: catálogo, ventas, favoritos, perfil y panel de gerencia.

API Backend

Servidor en Node.js + Express con Sequelize y base de datos MySQL. Expone los endpoints REST y guarda las fotos de productos.

Panel web

Panel administrativo en HTML/CSS/JS servido por el propio backend. Dashboard, productos, movimientos, estadísticas y usuarios.

Base de datos

MySQL con las tablas Users, Products y Sales. Las tres partes leen y escriben los mismos datos.

3. Funcionalidades implementadas

Autenticación

  • Login contra la base de datos con contraseñas encriptadas (bcrypt).
  • Sesión de usuario real en toda la app (nombre, correo, rol).
  • Roles: Gerente (acceso total) y Empleado.

Productos

  • Catálogo cargado desde la base de datos, con fotos.
  • Agregar, editar y eliminar productos (con imagen).
  • Búsqueda, filtro por categoría y orden por más vendidos.

Ventas e inventario

  • Registro de ventas que descuenta el stock real.
  • Notificación automática cuando el stock queda bajo.
  • Historial de movimientos.

Empleados y reportes

  • Crear y eliminar empleados (guardados en la base).
  • Favoritos / "Lo más vendido" con datos reales.
  • Reportes: KPIs, más vendidos, ventas por empleado, stock por categoría.

4. API Backend (endpoints)

El servidor corre en http://localhost:3000 y expone estos endpoints REST:

MétodoRutaDescripción
POST/usuarios/loginInicio de sesión (devuelve rol y datos del usuario)
GET/usersListar usuarios/empleados
POST/usuariosCrear usuario/empleado
DELETE/users/:idEliminar empleado
GET/productosListar productos (solo activos)
POST/productosCrear producto (con foto, multipart)
PUT/productos/:idEditar producto
DELETE/productos/:idEliminar producto
POST/ventasRegistrar venta (descuenta stock)
GET/ventasListar ventas / movimientos

Las imágenes de productos se guardan en backend/uploads/ y se sirven en /uploads/.... El panel web se sirve en /panel/.

7. Cómo ejecutar el proyecto

1) Base de datos (MySQL)

Importar el archivo backend/genali_shop.sql en MySQL Workbench (crea la base genali_shop y la tabla de usuarios).

2) Backend

Configurar la contraseña de MySQL en backend/.env y arrancar:

cd backend
node server.js

Debe mostrar «Backend corriendo en http://0.0.0.0:3000» y «Base de datos sincronizada correctamente».

3) Aplicación móvil

flutter run

4) Panel web

Abrir en el navegador: http://localhost:3000/panel/

Notas técnicas: las contraseñas se almacenan encriptadas con bcrypt. El rol de gerente da acceso al Panel de Gerencia y al panel web. Las categorías del panel se calculan a partir de los productos, y los "movimientos" corresponden a las ventas registradas.
